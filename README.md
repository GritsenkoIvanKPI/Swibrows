# SWIBROWS — курс по удалению пигмента

Одностраничный сайт курса Светланы SWIBROWS по удалению перманентного макияжа.
Bilingual landing page (RU / FR) for Svetlana SWIBROWS' pigment-removal training course.

## Запуск / Running locally

```bash
npm install          # puppeteer, только для скриншотов
node serve.mjs       # http://localhost:3001
```

Сайт — один файл `index.html` со встроенными стилями и скриптом.
Внешних зависимостей во время выполнения нет, кроме шрифтов Google Fonts
(Playfair Display + Inter Tight).

## Структура / Structure

```
index.html            весь сайт: разметка, стили, скрипт
assets/               изображения, подготовленные для веба (WebP/JPEG)
source/
  SWIBROWS_course.txt исходный текст курса (RU + FR) — источник всех текстов
  Загальна інформація.txt  информация о студии и услугах
  faq/                исходный документ с вопросами и ответами
  photos/             оригинальные фотографии от клиента
    who/              «Для кого моё обучение» (3 карточки)
    difficult-cases/  «Я знаю, с какими сложными случаями…»
    about/            «Знакомы мы?»
    works/            «Примеры моих работ»
    faq/              фото для блока вопросов
    hero-cutout-source.png  вырезанное фото для первого экрана
serve.mjs             локальный статический сервер
screenshot.mjs        скриншот страницы через puppeteer
```

Имена папок в `source/photos/` — латиницей: исходные названия содержали
скобки, пробелы и кириллицу (в одном был замыкающий пробел), что ломается
на части файловых систем.

## Языки / Languages

Переключатель RU/FR в шапке. Обе версии лежат в одном файле:
`<span class="ru">` / `<span class="fr">`, переключение — атрибутом
`data-lang` на `<html>`, выбор сохраняется в `localStorage`.
